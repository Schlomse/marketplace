Actions

Graceful stop: switch to the console terminal that opened when you hit “Start server” and type stop — this lets the server save the world properly.
Force stop kills the Java process directly (matched by jar file name) and should only be used if the server is stuck, since it skips the normal save routine.

Activity log

This log only shows actions triggered from this tab. The actual server output (chat, join/leave, errors) appears in the terminal window itself — RelateCore's plugin bridge doesn't stream terminal output back into tabs, so the terminal is the real console.
